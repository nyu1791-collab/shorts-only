# 媒体別の書き出しメモ

完成動画を各媒体へ出す時の確認点。**書き出しの要件であり、制作を止める検査ではない。** 媒体の数値は変わるので、投稿前に投稿画面と公式ヘルプを優先する。元の記録は 2026-09-30、再確認は 2026-11-01。

確認の表記：
- **本文確認**：公式ページの本文を取得して確認
- **抜粋のみ**：本文を取得できず、公式ページの検索結果の抜粋で確認。投稿前に画面で確かめる

## 共通

- クリーンなマスターを一つ保管し、派生版はそこから作る。別の媒体に投稿した再圧縮版から作らない。他媒体の透かしも持ち込まない。
- 本アプリの既定の MP4 は 720×1280 の H.264 / AAC / faststart。fps は素材に従う（指定なし）。これは制作の既定で、各媒体の最大値や唯一の正解ではない。
- UI に隠れる端の固定値は決めず、投稿画面のプレビューで字幕と文字を確かめる。
- 外部字幕は焼き込みと同じ時刻から作る。アップロードを確認するまで「字幕設定済み」と呼ばない。
- 素材の権利と事実の出典は別に扱う。公式の素材でも、使用の許可は別に確かめる。

## 媒体ごとの見方

- **YouTube**：2026-08-24 の前後で視聴回数を単純に比べない。指標名と定義も一緒に記録する。維持率は離脱・再視聴の箇所と、冒頭の期待との一致を見る診断材料で、再現の保証ではない。
- **Instagram**：固定のアルゴリズム説や一律の尺を規則にしない。Trial Reels は使えるアカウントだけの選択肢で、到達は約束しない。
- **X**：上限は会員区分で違うので、アカウントの画面で確かめる。自然流入と広告は別に測る。

## 公開後の記録

投稿ごとに、媒体、自然流入か広告か、形式、尺、投稿日、指標名と定義、結果を残す。見えない指標は `UNAVAILABLE` とし、推定で埋めない。一度の伸びを法則にせず、次に変える要因は一つにする。
