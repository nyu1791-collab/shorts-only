# 独立した構成

```text
main.py / run-windows.cmd
  src/shorts_only/
    cli.py          コマンド入口
    store.py        自分のSQLiteと作業記録
    settings.py     自分のプリセットと保存先
    standalone.py   取得・区間選定・字幕・MP4・続行
    gemini.py       任意のVertex接続・選定・Transcribe・整文
    engine.py       素材一覧・ドラフトの再利用
    timeline.py     元の時刻から編集後の時刻への対応
    capcut.py       ローカルのCapCutドラフト生成
    handoff.py      汎用の編集素材・OTIO・CSV・SRT出力
```

他リポジトリのソース、Python環境、Actions、DBを使用しません。ClipForge本体は変更しません。

`run` は自分の元動画を一度取得し、採用区間と素材の参照を保存します。既定の基本モードは区間指定・SRT・間隔抜粋を使用します。明示したAIモードだけが、自分のGoogle Cloud接続から指定モデルを呼びます。

ドラフトだけなら元動画の参照区間を保存して再描画を省きます。MP4が必要な場合だけFFmpegを使います。取得済み素材、完了したMP4、API応答、ドラフトの再利用は、このリポジトリの保存情報だけで行います。

原字幕の時刻・話者・元本文を保持し、プレビューやカット後の字幕は区間対応表から配置します。単語時刻をSRTから捏造しません。同時発話の表示は別トラックを使います。

尺・本数・演出数の目標不足で停止・水増し・追加モデル査読をしません。素材不存在や認証・通信失敗は記録し、成功と偽りません。制作できた区間は保持します。
